# FoodReservation

FoodReservation is a web application that allows users to view daily food options and reserve meals. Admins can manage food items, view reservations, set deadlines for reservations, and make updates as needed. This project uses **Pure PHP** for the backend, **MySQL** for the database, and **Bootstrap 5**, **JavaScript**, and **AJAX** for the frontend.

---

## Features

### User Features:
- **View Daily Foods**: Users can see the available food options for each day of the week.
- **Reserve Meals**: Users can reserve meals by selecting their preferred options.
- **Real-Time Updates**: Changes made by admins (e.g., updating food options or setting deadlines) are reflected in real-time for users.

### Admin Features:
- **Manage Food Options**: Admins can add, edit, or delete food items for each day.
- **View Reservations**: Admins can view all reservations made for each day.
- **Set Reservation Deadlines**: Admins can define deadlines for meal reservations.
- **Edit Existing Foods**: Admins can modify details of existing food items (e.g., name, description, price).

---

## Technology Stack

- **Backend**: Pure PHP for server-side logic and MySQL for database management.
- **Frontend**: Bootstrap 5 for responsive design, JavaScript for interactivity, and AJAX for asynchronous data handling.
- **Database**: MySQL for storing user data, food details, reservations, and deadlines.
